# Gemini CLI pointer

Gemini CLI loads `GEMINI.md` context files. Add a pointer in your global
`~/.gemini/GEMINI.md`:

```
See the work-management playbook at ~/workspace/dotfiles/workagent/AGENT.md and follow it.
```

(If you prefer, symlink or include the file directly per your Gemini setup — the file
remains the single source of truth.)
